# Personal AI Assistant

AI Assistant is optional and off by default. Open it from All tools or command search, enable it, and connect **your own** account. No developer account, personal key, token, document text or conversation is included in the installer or ordinary settings. Opening the dialog does not contact an AI service.

## Connections

- **ChatGPT subscription:** Continue with ChatGPT opens OpenAI authorization in your browser. PdfCraft is an independent open-source native public client, using PKCE, fresh state/nonce, the loopback callback and the client ID issued by OpenAI. It does not read Codex or ChatGPT desktop credentials. Account selection is explicit. Models come from this account's public model catalog; inference uses the public Responses API with plan-usage consent. Limits and eligibility belong to the user's plan. Rejection or exhausted usage never falls back to API billing.
- **Claude subscription:** install the official native Claude Code CLI first, then sign in from PdfCraft. This uses a separate `CLAUDE_CONFIG_DIR` inside this user's PdfCraft Assistant data directory. Requests disable tools, MCP, hooks and persisted CLI sessions, and send reviewed PDF text through stdin. Environment API keys, OAuth overrides and cloud-provider flags are removed from the child process. An older CLI missing the required safety switches fails rather than silently dropping them.
- **OpenAI API / Claude API:** explicitly select the API provider and enter your personal key in the masked field. API billing is separate from chat subscriptions. PdfCraft stores keys in the current user's Windows Credential Manager, macOS Keychain or Linux Secret Service. An unavailable store returns an error; there is no plaintext-file fallback.

ChatGPT tokens also use that OS store, with bounded chunked records and an atomic manifest to preserve an old session if rotation fails. Only non-secret provider/model/account identifiers go into normal preferences. Disconnect removes PdfCraft's local session and attempts provider revocation when network access is permitted. If remote revocation cannot be confirmed, the UI says to disconnect PdfCraft in ChatGPT settings too. Claude logout affects the separate PdfCraft CLI profile.

## Read, review, send

Choose the current page, all pages or selected pages. **Review PDF text** extracts locally from the current document state, with page markers and copy-permission checks. Read and remove sensitive passages before **Send reviewed text**. Only this reviewed text and the task/question go to the selected provider. Scans need OCR first; images and the PDF binary are not uploaded. Requests are bounded to 256 pages, 200 KB of reviewed text and an 8 KB question. An oversized source is refused rather than silently truncated.

Summaries, answers, translations and edit suggestions are read-only. Source text is marked untrusted in the instruction and prompt. No model tool or document-edit capability is supplied. Review accuracy and page citations yourself. A changed/switched document discards stale extracted text and answers. Cancel discards the eventual result; a request already transmitted may still count toward provider usage. Provider retention rules apply even though OpenAI requests set `store: false` and Claude CLI session persistence is disabled.

## Headless use

`ai_prepare` extracts text locally without network. `ai_assist` takes `provider`, `model`, optional `account`, `task` (`summary`, `suggestions`, `ask`, `translate`), `question` and either `reviewed_text` or selected pages. Sending, model discovery and sign-in require explicit `pdfcraft-cli --network`. `ai_accounts` lists only PdfCraft's saved profiles. `ai_login_start` returns an authorization URL; open it and poll `ai_login_finish`, or cancel that pending login. `ai_claude_login` uses the separate official CLI profile. `ai_disconnect` removes a selected connection. `ai_key_connect` imports only the explicitly selected provider's matching environment variable; keys are never tool arguments or results. Automation does not implicitly import environment keys for inference.

Synthetic checks cover bounded text extraction, no PDF edits, the network gate, strict callback state/client checks, API/subscription separation, incomplete streams, token-store rotation rollback, disabled CLI execution features, settings privacy and stale worker results. Live provider sign-in/inference, native Linux/macOS credential stores and Claude CLI login have not been exercised on this machine. Browser/WASM displays a desktop-connection notice. New assistant labels are currently English. This addresses the requested workflow behind upstream #4150 and #3112 without adopting conflicting PR #182's older settings/key storage.
