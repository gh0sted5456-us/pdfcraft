# Lion PDF 1.0.0

Lion PDF is the personal PdfCraft fork maintained by @gh0sted5456-us. This version brings the reviewed interface and tool integrations into one release.

- Lion PDF application, installer, shortcut and update branding; the existing engraved lion on the application popup taskbar.
- Centered About tabs, text and community links at normal and narrow window widths.
- Popup resizing from edges/corners, bounded layouts and preserved minimized drafts. The Discord title-bar shortcut is hidden by default and can be enabled in Preferences → Appearance.
- Native Excel export through the File menu, Export To chooser and automation, with page-range selection.
- Removable printer marks with selected-page controls, preserved existing fonts and physical dimensions on enlarged page units.
- Page Properties tab order for selected pages, including right-bound documents, indirect values and stale-selection protection.
- Atomic basic hairline repair with selected-resource copies, bounded traversal, physical page units, visible analysis errors, save/reopen and Undo support.
- Thumbnail cache cleanup when Print or other thumbnail consumers close while the main page is still loading.

The established Glass, editing/group selection, page protection, signing, local OCR, templates, per-user AI connections and Confidential controls remain in the fork. Development status badges are removed from tool rows; unavailable tools remain unavailable.

Existing installations retain their application/settings identifiers, PDF associations, update repository and PdfCraft Printer name. Product packages use version 1.0.0. The release versioner uses the source version as a floor, reserves published/draft versions and increments later patches without downgrading installed copies.

This is not a claim of complete PDF-tool parity. Hairline repair uses a geometric-mean scale for anisotropic transforms; optional Type 3 glyphs use a nominal 10 pt size, and nested glyph/pattern Forms and annotation appearances are not traversed. Other unfinished proposals and qualification requirements are recorded in [the integration inventory](fork-tool-integration.md) and the machine-readable parity checklist.
