## Fork adaptations and qualification

The bookmark dialog uses the fork's centered heading/actions, scrollable body
and popup taskbar. Actions use the shared matte blue cancellation and green
confirmation roles, with Cancel to the left of Create. Its selected styles survive minimize/restore. Widget deletion
continues to honor page locks and leaves the document unchanged when refused.

A new extreme-page regression checks that sequential and threaded image export
return an error for `usize::MAX` without invoking the output sink or panicking.
Both local fixes first failed their synthetic regressions, then passed.

No hardware CAC checks, native Linux/macOS runtime checks or new installer
installation are performed by this local integration pass. Hosted platform CI
must pass before promotion to the fork's main branch.
